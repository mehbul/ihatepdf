## Measure the result

Compare equivalent reporting windows after the metadata update. Keep repository views, unique visitors, clones, stars and forks distinct from hosted-app visitors or completed PDF tasks. Clones can include automated activity. GitHub referrers do not identify the search query or which visitor starred or forked the repository. Search Console provides a separate view of website search queries and clicks when available.
